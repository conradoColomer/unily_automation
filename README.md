# Proyecto de Automatización con Selenium

Este proyecto es una demostración de pruebas automatizadas utilizando **Selenium** y **Pytest** para interactuar con un sitio web de ejemplo.

## Enlaces

- [Mi LinkedIn](https://www.linkedin.com/in/conrado-mendez-colomer-454b221b1/)

## Requisitos

Para correr este proyecto, asegúrate de tener los siguientes requisitos instalados:

1. **Python 3.13** (o superior)
2. **Selenium**: Para interactuar con el navegador web y automatizar las interacciones.
3. **Pytest**: Para ejecutar las pruebas.
